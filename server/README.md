# SIGNO API

> Дээд хэсэг (`---` хооронд) нь Hugging Face Spaces-ийн тохиргоо. Устгахгүй.

## Харилцах demo

`GET /api/v1/talk/speech?phrase=greeting` эсвэл `phrase=thanks` нь `audio/mpeg` буцаана.
Бусад өгүүлбэрийг зөвшөөрөхгүй. Хуучин health/detect гэрээг өөрчлөөгүй.

`server/.env.example`-ийг үндэслэж `server/.env` үүсгээд
`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` тохируулна. Түлхүүр mobile env-д орохгүй.
`ELEVENLABS_MODEL=eleven_v4`: албан ёсны жагсаалтаар монгол хэл дэмждэг.
Eleven v3, Multilingual v2 нь монголыг албан ёсоор дэмждэггүй.

```bash
cd server
set -a
source .env
set +a
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Mobile-ийн `EXPO_PUBLIC_API_URL`-д энэ серверийн хаягийг тавьж Expo-г дахин асаана.
Утаснаас Mac-ийн localhost биш, ижил Wi-Fi дахь IP ашиглана. APK-д HTTPS хэрэгтэй.
Web дээр ажиллуулахдаа Expo-ийн origin-ийг `CORS_ORIGINS`-д тохируулна.

ElevenLabs руу зөвхөн хоёр бэлэн өгүүлбэрийн бичвэр илгээнэ; хэрэглэгчийн микрофон ашиглахгүй.
Энэ урсгал дохионы хөдөлгөөнийг AI-аар танихгүй: хэрэглэгч бэлэн дохиотой карт сонгодог.
Үүсгэсэн аудиог файлд хадгалахгүй, процессын RAM-д хамгийн ихдээ хоёр клип түр ашиглана.
Хоёр клипийн анхны үүсгэлт provider-ийн quota/төлбөр ашиглана. Сервер дахин асвал RAM cache арилна.
Түлхүүр дутвал `503 TTS_NOT_CONFIGURED`, provider алдаанд `502` буцаана.
Бичвэр нь аудио амжилтгүй байсан ч дэлгэцэд үлдэнэ.

Дохионы эх сурвалж: [mnsl.mn — Сайн байна уу?](https://mnsl.mn/ug/28-сайн-байна-уу/),
[Баярлалаа](https://mnsl.mn/ug/137-баярлалаа/). SVG дараалал нь бичлэгээс хялбаршуулсан ноорог;
дохионы хөдөлгөөнийг бүтнээр нь эх бичлэгээр үзүүлнэ. SVG-ийн гарын хэлбэр, алганы чиглэл,
хөдөлгөөн, нүүрний хувирлыг дохионы хэл мэддэг хүнээр баталгаажуулах шаардлагатай.
Нийтийн release-ийн өмнө asset ашиглах эрхийг мөн баталгаажуулна.

## Яриа → дохионы demo

`POST /api/v1/talk/transcribe`: multipart form-ийн `audio` талбарт нэг богино аудио файл илгээнэ.
`audio/mp4`, `audio/m4a`, `audio/x-m4a`, `audio/webm`, `audio/wav` формат, файл ≤1MB.
App хамгийн ихдээ 8 секунд бичнэ. Сервер оролтын хэмжээг хязгаарлана;
аудионы бодит хугацааг сервер өөрөө хэмжиж баталгаажуулахгүй тул production-д нэмэлт шалгалт хэрэгтэй.
Хариу: `{ "text": "Сайн байна уу?" }`; mobile нь zod-оор шалгана.
Алдаа хуучин `{ "error": { "code", "message" } }` бүтцээр ирнэ.
`ELEVENLABS_STT_MODEL=scribe_v2`, API key-ийн Speech to Text эрх шаардлагатай.

Хэрэглэгч «Сонсох» дарж микрофоны зөвшөөрөл өгсний дараа л бичнэ.
Сервер аудиог диск / логт хадгалахгүй, харин ElevenLabs руу илгээдэг.
Provider өөрийн өгөгдөл хадгалах бодлоготой: энэ demo zero-retention амлахгүй.
Нийтийн demo tunnel-ийн төлбөртэй хүсэлтийг хязгаарлахын тулд серверийн нэг процесст
хамгийн ихдээ 30 удаа яриа танина (алдаатай provider хүсэлт ч тоологдоно).
Хэтэрвэл `429 STT_DEMO_LIMIT`; серверийг дахин асаахад тоолуур шинэчлэгдэнэ.
Зөвшөөрсөн хүний богино demo яриа ашиглана; нийтэд нээлттэй production серверт
authentication, rate limit болон retention-ийн баталгаажуулалт шаардлагатай.

«Сайн байна уу?», «Баярлалаа», «Уучлаарай», «Баяртай»-д эх дохионы видео харуулна.
«Танд юугаар туслах вэ?» танигдвал **зөвхөн «туслах» үгийн видео**, бүтэн орчуулга биш гэсэн
тайлбартай гарна. Танигдсан бусад өгүүлбэрт зохиомол дохио гаргахгүй.
Mobile-ийн нэмэлт тохиргоо: `EXPO_PUBLIC_SORRY_SIGN_URL`, `EXPO_PUBLIC_GOODBYE_SIGN_URL`,
`EXPO_PUBLIC_HELP_SIGN_URL` (`mobile/.env.example`-ээс харна).

Mobile `.env`-д `EXPO_PUBLIC_USE_RN_FETCH=1` мөн хэрэгтэй. SDK 57 нь global fetch-ийг
expo/fetch-ээр сольдог бөгөөд энэ нь native `{ uri, name, type }` multipart файл дэмжихгүй.
Энэ тохиргоо React Native fetch-ийг үлдээж, микрофоны файлыг серверт илгээх боломж олгоно.
Env өөрчилсний дараа `bunx expo start --tunnel --clear` гэж Expo-г дахин асаана.
