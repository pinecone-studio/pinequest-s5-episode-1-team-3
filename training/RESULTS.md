Бусад мөртэй тааруулахын тулд baseline-ийн 319 хэсэг = 48.7/цаг харьцаагаар хөрвүүлсэн: 36 хэсэг → 5.5.

**v0 тэмдэглэл**
- Зөвхөн ESC-50 (knock 40, alarm 40). Test-д knock 8, alarm 9 тул нэг алдаа ≈ 10%. Хонх, яриа ESC-50-д байхгүй.
- Baseline сирен, машины дохиог сэрүүлэг; хөлийн чимээ, бороог тогшилт гэж андуурсан. v0 зөвхөн царцааг сэрүүлэг гэж андуурсан.
- Босгыг train дээр GroupKFold CV-ээр сонгосон (knock 0.95, alarm 0.45), test-д хүрээгүй.

**v1 тэмдэглэл: серверт асаахгүй** (хонх baseline-аас муудсан: recall 0.75 → 0.00)
- FSD50K нэмэгдсэн test илүү бодит, хэцүү: baseline ч precision ~0.2 болж унасан.
- v1 нь худал мэдэгдлийг 26.3 → 2.3/цаг болгож бууруулсан ч recall хангалтгүй.
- Шалтгаан: урт бичлэг. >5 сек бичлэгт recall 0.22–0.30, ≤5 сек бичлэгт 0.69–0.77. Хонхны бичлэг дунджаар 13 сек:
  бүтэн бичлэгийн дундаж богино дууг уусгадаг. Апп 3 сек тутам илгээдэг тул сургалт, сервер хоёр зөрж байна.
- CV дээр босго бүгд 0.95 (шалгасан хамгийн өндөр утга) гарсан: precision 95%-д train дээр ч хүрээгүй.

**v2 тэмдэглэл: серверт асаах эсэхийг баг шийднэ**
- Бичлэгийг апп шиг 3 сек хэсэг болгосон. Мэдэгдлийн бичлэгээс YAMNet-ийн тухайн ангиллын оноо хамгийн өндөр хэсгийг л сургалтад авна.
- Train-ийн 20% дээр 12+3 тохиргоо харьцуулсан: hidden 256, L2 0.1 хамгийн сайн (mean AP 0.29; YAMNet-ийн оноо дангаараа 0.17).
- Baseline-тай харьцуулахад худал мэдэгдэл 48.7 → 5.5/цаг (9×), precision 2–4× сайн, харин recall бага (хонх 0.88 → 0.13).
- Precision 95% train дээр ч хүрэхгүй тул босго бүгд 0.99. F1 босгыг туршсан: recall бага зэрэг өссөн ч худал мэдэгдэл 13.3/цаг болсон.
- Гол хязгаар нь өгөгдөл: train-д хонх 29, тогшилт 113 бичлэг. FSD50K dev-д 3× их (хонх 107, тогшилт 270), гэхдээ 24.7GB.
  Дараагийн алхам: dev татах, багийн гэрийн бичлэг (жинхэнэ хонх, тогшилт, гэрийн шуугиан).

**v3 тэмдэглэл: серверт асаах эсэхийг баг шийднэ**
- Test нь v2-тэй яг ижил. Шалгасан: dev-гүйгээр дахин сургахад v2-ийн тоо (0.45/0.56, 0.50/0.13, 0.68/0.46, 5.5) яг гарсан.
- Нэмсэн (зөвхөн train): FSD50K dev-ээс хонх 107, тогшилт 270, андуурагдах дуу ~1500 (утас, сүмийн хонх, хаалга хаах,
  шүүгээ …, ангилал бүрээс ≤120), яриа 300. Test-д орсон хүний (uploader) бичлэг алгассан. Train: хонх 29 → 136, тогшилт 113 → 362.
- `download_fsd50k.py`: 30GB zip-ийн оронд HF Hub-ийн толиос (Fhrozen/FSD50k) зөвхөн хэрэгтэй ~12 800 файл татна.
- Dev-ийн сэрүүлгийг (343) нэмэхэд сэрүүлгийн precision 0.68 → 0.41 болж унасан: dev-ийн «Alarm» хэт өргөн
  (аянга, хашгирах …). Тиймээс хассан. Анхаар: энэ сонголтыг test-ийн тоогоор хийсэн тул test бага зэрэг өөдрөг байж болно.
- v2-оос: хонх recall 0.13 → 0.88 (8-аас 7), бүх ангиллын precision өссөн, худал мэдэгдэл 5.5 → 3.7/цаг.
  Харин сэрүүлгийн recall 0.46 → 0.33, тогшилт 0.56 → 0.48.
- Baseline-аас: худал мэдэгдэл 48.7 → 3.7/цаг (13×), precision 2–4×. Хонхны recall ижил (0.88), тогшилт 0.72 → 0.48, сэрүүлэг 0.70 → 0.33.
- Босго бүгд 0.99 хэвээр (precision 95% train CV-д хүрэхгүй). Recall-ыг хязгаарлаж байгаа гол зүйл.
- Test-д хонх ердөө 8 бичлэг: нэг алдаа = 12.5%. Багийн гэрийн бичлэгээр дахин хэмжих хэрэгтэй.

**v2 дахин тэмдэглэл: серверт асаахгүй** (v3 илүү сайн)
- Түүхий бичлэггүйгээр, зөвхөн HF-ийн `sonsyo/sonsyo-sound-data` → `features.npz`-ээр өөр компьютер (Windows) дээр дахин сургасан.
  Энэ файлд v2-ийн өгөгдөл байгаа (FSD50K dev-гүй): train-д хонх 29, тогшилт 113.
- Baseline-ийн precision / recall дээрх мөртэй яг ижил гарсан: test өгөгдөл, серверийн кодын зам зөв.
- Худал мэдэгдэл v2-тэй ижил (36 хэсэг). Харин толгойн тоо бага зэрэг зөрсөн: тогшилт 0.45/0.56 → 0.54/0.60, сэрүүлэг 0.68/0.46 → 0.59/0.48.
  Seed ижил ч Mac, Windows-ийн тооцооллын сан өөр тул сургалт өөр замаар явсан. Хонх ижил (0.50/0.13).
- Босго бүгд 0.99 хэвээр (precision 95% train CV-д хүрэхгүй).
- v3-ийн `features.npz` (FSD50K dev-тэй)-ийг HF dataset-д оруулбал түүгээр дахин сургаж, v3-ийг давтан гаргах боломжтой болно.
