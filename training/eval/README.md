# Зарлалын бичлэг ба үнэлгээ

Whisper fine-tune, үнэлгээнд зориулсан **300 зарлал** (банк 100, эмнэлэг 100, төрийн үйлчилгээ/ХУР 100).

| Файл | Юу вэ |
|---|---|
| `announcements.csv` | Уншиж бичүүлэх 300 мөр. `make_announcements.py`-ээр үүсгэнэ, **гараар засахгүй** |
| `make_announcements.py` | Хүснэгт үүсгэгч (seed тогтмол) |
| `check_announcements.py` | Мөр бүрийг серверийн парсераар уншуулж шалгана |
| `speakers.json` | Хэн сургалтад, хэн тестэд |
| `split_by_speaker.py` | Бичлэгийн жагсаалтыг хүнээр нь train/test болгож, алдааг шалгана |

```bash
python training/eval/make_announcements.py                       # хүснэгтийг дахин үүсгэх
python training/eval/check_announcements.py                      # парсер мөр бүрийг зөв уншиж байна уу
python training/eval/split_by_speaker.py data/manifest.csv data/ # бичлэгийг хуваах
```

## Хүснэгтийн бүтэц

| | банк | эмнэлэг | төрийн үйлчилгээ | нийт |
|---|---|---|---|---|
| Дугаар (`queue`) | 100 | 60 | 100 | 260 |
| Нэр (`name`) | — | 40 | — | 40 |
| Үүнээс `test` | 20 | 20 | 20 | **60** |

- Дугаарыг 3 янзаар уншина (`style`): `words` «хорин дөрөв», `zero` «тэг хорин дөрөв», `digits` «нэг тэг тав».
- **Банк:** бүгд латин үсэгтэй (A, B, C, D → «A-», «Бий», «Си», «Дий»), дугаар 1–150.
- **Эмнэлэг, төрийн үйлчилгээ:** 75% нь кирилл үсэгтэй (А, Бэ, Вэ, Гэ, Дэ, Е), 25% нь зөвхөн тоо. Дугаар: эмнэлэг 1–300, төрийн үйлчилгээ 1–200.
- `bank_001`–`004`-ийг багийнхан гараар зассан (`FIXED_ROWS`). Бусад банкны мөр тэдгээрийн хэв маягаар үүснэ.
- `check_announcements.py`: 300/300 мөрөнд дугаар, цонх, нэр зөв ялгарна.

> **Мэдэгдэх зүйл (3, 5-р хүн):** парсер «Бий», «Си», «Дий»-г үсэг гэж танихгүй (76 банкны мөр).
> Мэдэгдэл гарна, гэхдээ зөвхөн дугаараар тулгана: `B-024`, `C-024` хоёрыг ялгахгүй.
> Мөн апп `lib/ticket.ts` латин B, C-г кирилл В, С болгодог, сервер латин b-г Б гэж уншдаг тул латин үсэгтэй тасалбарын дүрмийг нэгтгэх хэрэгтэй.

> **Мэдэгдэх зүйл (5, 7-р хүн):** парсер зөвхөн «цонх»-ыг цонх гэж таньдаг. Эмнэлгийн «нэг зуун найман өрөөнд» гэсэн 56 мөрөнд
> дугаар зөв таарна, харин өрөөний дугаар `window: null` гарна (мэдэгдэл дээр өрөө харагдахгүй). Хүснэгтэд `place` баганаар ялгасан.

## Тестийн 2 хүн

`speaker_06`, `speaker_07` **тестийн** хүмүүс. Тэдний бичлэг сургалтад **хэзээ ч орохгүй**.

Хэнийг 06, 07 болгох вэ (багаараа шийдээд Drive-ийн жагсаалтад бичнэ):
1. **1 эрэгтэй, 1 эмэгтэй.** Загвар хоёр хоолойд хоёуланд нь ажиллахыг шалгана.
2. **Бусад 5 хүнээс өөр хоолой** (нас, аялга). Ах дүү, нэг гэрийн хүн 2 талд хуваагдахгүй.
3. **Whisper-ийг fine-tune хийдэг хүн (5) биш.** Тестийн бичлэгийг сонсож, загвараа түүнд тааруулах уруу таталтаас сэргийлнэ.
4. Демо хийх өдөр ирж чадах хүн байвал сайн. Демод «загвар өмнө нь сонсож байгаагүй хоолой» гэж шударгаар хэлж болно.

Тестийн хүмүүс зөвхөн `split=test` 60 мөрийг, сургалтын хүмүүс зөвхөн `split=train` 240 мөрийг уншина.
Ингэснээр хоолой ч, **бичвэр** ч давхцахгүй (Whisper өгүүлбэрийг цээжилсэн эсэхийг тест илрүүлнэ). `split_by_speaker.py` үүнийг шалгана.

## Бичлэг хийх заавар

1. Бичихийн өмнө **зөвшөөрөл** авна (аман биш, бичгээр/мессежээр).
2. Хүн бүр өөрийн мөрүүдийг уншина:
   - `speaker_01`–`05`: `train` 240 мөр (≈ 20 мин). Ядарвал 2 өдөрт хувааж болно.
   - `speaker_06`, `07`: `test` 60 мөр (≈ 5 мин).
3. Утасны дуу бичигчээр, **нэг мөр = нэг файл**: `speaker_03/bank_017.m4a`. Мөрийн өмнө, ард 0.5 сек чимээгүй.
4. Зарлал шиг чанга, тод. Өрөөний чимээтэй орчинд (коридор, кафе) нийт мөрийн ~⅓-ийг бичнэ.
5. Алдаж уншвал дахин бич. Бичвэрээс өөрөөр уншсан бол `manifest.csv`-д `prompt_id`-г бүү тавь.
6. Файлуудыг багийн Drive / HF private dataset руу. **Git-д оруулахгүй.**
7. `manifest.csv` (`path,speaker,prompt_id`) бөглөөд `split_by_speaker.py` ажиллуул. Алдаагүй бол train/test бэлэн.
